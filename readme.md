# Requirements

1. Gran Turismo 5 Version 2.11

2. Unpacked game files and RPCS3 direct access patch. ([guide.](https://nenkai.github.io/gt-modding-hub/ps3/basics/easier_ways_to_mod/))


⠀
# Installation

1. Extract "ssrMod_unpacked.zip"
   
2. Go into "[rpcs3_dir]/dev_hdd0/game/[gt5build]/USRDIR/direct/crs"
   
3. Drag and drop the morning ".envptr" files into "crs"


⠀
# Uninstallation

1. Drag and drop the night ".envptr" files included in the mod into "crs"
